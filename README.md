## Features

- Responsive design for mobile, tablet, and desktop
- Dark/light mode toggle
- Smooth scrolling navigation
- Project showcase with live demo and source links
- Contact form
- Downloadable resume

## Built with

- HTML5
- CSS3
- JavaScript (vanilla)
- Some Other Useful Languages like React, Node.js, etc.
